루틴로그 개인정보처리방침

시행일: 2026년 8월 30일 · 마지막 수정일: 2026년 8월 30일

핵심 안내: 루틴로그(RoutineLog)는 회원가입이나 자체 서버를 사용하지 않습니다. 루틴과 기록은 기본적으로 사용자의 기기에만 저장되며, 운영자에게 자동 전송되지 않습니다.

1. 적용 대상 및 운영자

이 방침은 모바일 애플리케이션 루틴로그(RoutineLog)에 적용됩니다. 개인정보 관련 문의처는 basstrio1223@gmail.com입니다.

2. 앱이 기기에 저장하는 정보

루틴로그는 다음 정보를 사용자가 입력하거나 선택한 기기 내부에 저장합니다.

  • 루틴 이름, 단위, 목표, 색상, 메모, 반복 일정 및 알림 시간
  • 날짜별 숫자 기록, 완료 여부 및 기록 메모
  • 카테고리, 화면 테마, 언어, 카드 크기 등 앱 설정
  • 앱 내 알림함의 읽음 여부 및 알림 표시 기록

이 정보는 앱 기능 제공을 위해 기기 내부 SQLite 데이터베이스에 저장됩니다. 현재 버전은 계정 생성, 로그인, 클라우드 동기화 또는 자체 서버 전송 기능을 제공하지 않습니다.

3. 권한 및 알림

사용자가 루틴별 시간 알림을 켜거나 설정에서 알림 테스트를 요청한 경우에만, 루틴로그는 기기 알림 권한을 요청합니다. 알림은 사용자의 기기에서 예약되며, 알림 전송을 위해 운영자 서버에 루틴 정보나 기기 식별 정보를 보내지 않습니다.

루틴로그는 현재 위치, 연락처, 사진, 마이크, 카메라 또는 통화 기록에 접근하거나 수집하지 않습니다.

4. 백업 파일

사용자가 ‘백업 파일 만들기’를 직접 선택하면, 루틴과 기록이 포함된 JSON 파일이 기기에 생성됩니다. 사용자가 운영체제의 공유 화면에서 직접 대상과 위치를 선택한 경우에만 해당 파일이 공유될 수 있으며, 루틴로그 운영자는 백업 파일을 수신하거나 보관하지 않습니다.

‘백업 파일 복원’은 사용자가 직접 선택한 JSON 파일을 기기 내부 데이터로 복원합니다. 백업 파일의 보관·공유·삭제는 사용자가 선택한 저장 공간 또는 공유 서비스의 정책에 따릅니다.

5. 제3자 제공, 광고 및 분석

현재 버전의 루틴로그는 사용자의 루틴·기록 데이터를 제3자에게 판매, 공유 또는 제공하지 않습니다. 또한 광고 SDK, 행동 분석 SDK, 광고 식별자 기반 추적 또는 자체 분석 서버를 사용하지 않습니다.

6. 보관 및 삭제

기기 내부 기록은 사용자가 삭제하거나 앱 설정의 ‘모든 데이터 초기화’를 실행할 때까지 기기에 보관됩니다. 앱을 삭제하면 일반적으로 앱 내부 데이터도 기기에서 삭제되지만, 사용자가 직접 저장한 백업 파일은 별도로 삭제해야 합니다.

사용자가 문의 이메일로 자발적으로 보낸 정보는 문의 답변을 위해서만 사용하며, 처리 목적이 달성된 뒤 지체 없이 삭제합니다. 법령상 보관 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

7. 이용자의 선택과 문의

알림 권한은 기기 설정에서 언제든지 변경하거나 철회할 수 있습니다. 앱 내부 데이터는 설정의 초기화 기능 또는 각 루틴·기록 삭제 기능으로 관리할 수 있습니다. 개인정보 관련 문의는 basstrio1223@gmail.com으로 보내 주세요.

8. 방침 변경

서버 동기화, 광고, 결제 또는 새 데이터 처리 기능이 추가되는 경우에는 실제 배포 전에 이 방침을 업데이트하고, 앱의 업데이트 소식과 스토어 등록정보를 통해 안내하겠습니다.
